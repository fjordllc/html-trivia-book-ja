# 付録 B HTML を作った人たち

HTML は一人で完成させた仕様ではありません。ここでは、発明、仕様の編集、表現の分業に関わった三人を、残された一次資料から紹介します。

## Tim Berners-Lee（ティム・バーナーズ＝リー） — Web の仕組みを提案した人

1989 年の [Information Management: A Proposal](https://www.w3.org/History/1989/proposal.html)で、CERN 内の人・装置・文書の関係をたどれる情報管理を提案しました。最初の Web の実装へ進み、HTML、URL、HTTP を組み合わせた仕組みを形にしました。

公開の条件を整えたのは個人だけではありません。1993 年に CERN が Web のソフトウェアをパブリックドメインに置いた判断も普及を支えました。個人の発明と組織の判断を分けると、[第21章](../part6/chapter21.md)の歴史が見えやすくなります。

## Ian Hickson（イアン・ヒクソン） — 実装の振る舞いを仕様へ整理した人

HTML5 の編集を担った一人です。[W3C の2014年 HTML5 勧告](https://www.w3.org/TR/2014/REC-html5-20141028/)でも、編集者として名前を確認できます。パースやエラー回復を共通の規則へ整理する仕事は、本書の第2部と深く関わります。ただし、仕様全体を一人の成果とするものではありません。

ブラウザの実装を検査する [Acid3](https://www.webstandards.org/action/acid3/) の開発にも関わりました。仕様の文章と、実装がその規則を満たすかを調べるテストの両方が必要だったことを示す例です。

## Håkon Wium Lie（ホーコン・ウィウム・リー） — スタイルシートを提案した人

1994 年の [Cascading HTML Style Sheets — A Proposal](https://www.w3.org/People/howcome/p/cascade.html)で、HTML の要素へ表示上の指定を与えるスタイルシートを提案しました。著者の希望だけでなく、利用者やブラウザの設定との調整も含む提案です。

構造を記す HTML と、表示を指定する CSS の分業は、その後も多くの人によって発展しました。[第13章](../part4/chapter13.md)の font や center の話を読むときも、個々のタグの廃止だけでなく、表現をどの仕組みに担わせるかという変化として捉えられます。
